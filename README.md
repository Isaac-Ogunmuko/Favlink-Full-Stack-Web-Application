# FavLink - Full-Stack Web Application

A modern full-stack web application designed to manage, organize, and interact with your favorite online links in one centralized dashboard. Built with a responsive table layout, full CRUD capabilities, and persistent database storage.

## 🚀 Key Features

* **Custom Table Layout:** Clean, structured dashboard interface for viewing saved links.
* **Interactive Management:** Add new link entries and delete outdated ones seamlessly.
* **Persistent Storage:** Backend API connected to a secure database to keep your links saved across sessions.
* **Responsive Design:** Optimized for smooth navigation across different screen sizes.

---

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS (Hosted on Vercel)
* **Backend:** Node.js, Express.js (Hosted on Render)
* **Database:** MongoDB / PostgreSQL
